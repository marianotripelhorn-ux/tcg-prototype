# Board artwork

These are existing project assets shared with the Godot prototype.

- `arena-compass-source.png`: the original sword-free geometric arena artwork, copied unchanged from the Godot source. CSS maps its dark values to pale ivory at runtime.
- `cardback-gold.png`: the supplied Daggerlight gold card back, copied unchanged from the Godot assets.
- Champion figures, faction banners, and printed card faces continue to use the existing React assets.

Archivo Black is bundled in `public/fonts`; its OFL license is included beside the font.
